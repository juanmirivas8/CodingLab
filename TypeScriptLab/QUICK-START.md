# Quick Start - Configuración Rider 30 segundos

## 🎯 El Setup está LISTO

Las configuraciones de ejecución ya están creadas. Solo necesitas:

### Paso 1: npm install (Primera vez)
```bash
npm install
```

### Paso 2: Ejecutar en Rider
1. **Dropdown** (arriba a la derecha) → Selecciona **"TypeScript Lab - Dev"**
2. **Botón Play** (▶️) o presiona **Shift + F10**
3. **¡LISTO!** Se abre el navegador en http://localhost:8080

---

## Las 3 Configuraciones Disponibles

| Config | Comando | Cuándo usar |
|--------|---------|------------|
| **Dev** ⭐ | `npm run dev` | Inicio rápido, desarrollo completo |
| **Watch** 👀 | `npm run watch` | Ver cambios en tiempo real, fondo |
| **Serve** 🌐 | `npm run serve` | Servir archivos en http://localhost:8080 |
